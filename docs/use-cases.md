# Practical workflows

## Keyword snapshots

Use the primary Python example for five milk matches. Check the names: related chocolate can legitimately match. Preserve timestamps and store selection when comparing separate snapshots; no price-history product is provided.

## Batch query comparison

The batch script runs milk and bread separately with per-run spending caps. Keep its query label so cross-query duplicates are explicit. Edit the small list before starting more paid runs.

## Spreadsheet export

Export an existing Dataset with export_prices_csv.py. The client reads pages by returned row count, not an assumed immediate aggregate total, and accepts the final empty-page probe. Null and zero prices are distinct.

## Descriptions and store-specific selections

Enable includeDetails for available descriptions, ingredients and allergens. Discover stores before supplying servicePoint. Assortment changes by store and null prices do not prove absence or stock state. Promotions vary with time.
